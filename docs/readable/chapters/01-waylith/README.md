# Waylith 章节草稿

本目录用于整理《从启动到每一帧：Waylith 怎样驱动 RimWorld》的文章草稿。

正文工作文件是 [draft.md](draft.md)。初始内容承接共同修订的 [模块汇总稿 v0.2](../../14-waylith-summary-draft.md)，后续在本目录逐段整理成文。

当前为第一轮成文稿，继续用于共同阅读与校订。正文已整理 OnUpdate 内部层级，补充帧相关对象对照与时序图术语说明，并以菜单鼠标输入衔接输入、更新、采集和提交。完整源码节选保留，交换链重建与 TempJob 维护的补充说明采用可展开排版。

文章开头新增面向玩家的五点省流速览，概括线程分工、渲染等待、画面显示的阶段、最小化与失焦，以及 FPS 与游戏 tick 进度的区别。

本文采用静态源码阅读，尚未进行实际帧率与显示延迟测量。

文章沿已确定的顺序展开：Waylith 总览 → 引擎创建 → 初始化 → 两条线程与三个队列 → 主线程 → 渲染线程 → 渲染数据的交换与提交。

写作约定见 [系列大纲](../../00-series-outline.md)。源码引用保留原名，讲解用改名须在片段前逐项说明；展开方法前，先解释涉及的类、对象与主要数据。

仓库内的文档、图片与图源使用相对于当前 Markdown 文件的链接。源码引用采用“命名空间.类型名.cs:行号”，例如 `RimWorldWaylith.Bootstrap.cs:749`，作为本地核对用的文字定位；`analysis/decompiled/` 不随仓库上传。

已有阅读笔记和图源继续作为参考资料。正文中的图像与 SVG 沿用 `docs/readable/figures/` 中的文件。GameRoot、Root 的详细职责留在后续游戏流程研究；渲染内部数据与 pass 实现留在地图、空间和 UI 之后的渲染模块。
