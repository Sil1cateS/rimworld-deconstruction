# 第五章 · 线程：长任务与线程协作

本章于 2026-11-11 定稿，依据 RimWorld 1.7.4982 rev1280 的代码整理。

| 版本 | 内容 |
| --- | --- |
| [发布版 v1.0](release.md) | 沿任务队列、三种执行方式和两个案例讲清线程间的执行与等待，配有关键代码和流程图 |
