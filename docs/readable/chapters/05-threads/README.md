# 第五章 · 线程：长任务与线程协作

当前版本：[整合草稿 v0.1](draft.md)，2026-11-07。依据 RimWorld 1.7.4982 rev1280，供共同阅读与修订。

主线：登记任务 → 主线程选中与显示 → 同步、异步或迭代器执行 → 内部并行工作与等待 → 后续函数 → 主线程界面初始化。

案例包括自动存档、普通启动加载、XML 文件读取和交叉引用解析。各部分明确当前调用者、任务保存位置、等待点及返回后的执行位置。

图片、SVG 与可编辑 DOT 复用 [系列通用图目录](../../figures/)。源码采用文字定位，文档与图片使用相对链接。
