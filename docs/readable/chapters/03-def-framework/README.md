结构篇的发布版保留完整解析版的全部讲解、代码、案例、表格与配图，只删除精确源码及 XML 定位。

加载篇的发布版压缩类字段目录、读取器实现、泛型调用与收尾细节，保留加载主线、研究速度案例、教学补丁、必要代码和五张配图，移除外链与精确源码定位。完整解析版保留主线对象结构、较完整的源码节选、处理分支和核对入口。3.2 的字段读取图已重新安排循环回线、跳过分支与结束出口。

两篇的分工是：结构篇回答“文件和对象由什么组成、彼此是什么关系”；加载篇回答“谁按什么顺序读取、保存、连接和查询它们”。加载篇各部分先讲流程和代码，再用案例对照结果；完整解析版还在使用位置介绍主要类的字段与关系。

本组总结定义框架。实际 Thing 创建、组件生命周期、实例耐久与品质，以及最终属性计算，留到后续物品与相关系统模块。

代码节选保留源码命名；教学修改与调用示意单独注明。完整解析版采用“命名空间.类型名.cs:行号”的文字定位，对应本地反编译语料。文档、图片、SVG 与 DOT 图源均使用相对链接。
