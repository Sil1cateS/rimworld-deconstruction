本组总结通用框架。第一篇在适当位置加入具体定义，说明 XML 写法、类型分支和对象字段；第二篇先建立功能概览，各小节按“流程职责与输入输出 → 源码片段及执行解释 → 案例结果”展开，标题描述该步处理内容。研究速度案例保留在相应步骤之后，帮助对照数据变化。原版节选、教学修改和中间结果分别标明。目录选择和读取器等支线分支继续保存在研究笔记中。样例停在定义与配置结构，实际 Thing 创建、组件生命周期、实例耐久与品质，以及最终属性计算，留到后续物品与相关系统模块。

两篇的分工是：第一篇回答“文件和对象由什么组成、彼此是什么关系”；第二篇回答“谁按什么顺序读取、保存、连接和查询它们”。XML 模板规则在第一篇说明，执行位置在第二篇接回；公共方法在第一篇认识，实际调用时机在第二篇展开。

代码节选保留源码命名；通用语法示意单独注明。完整解析版与第二篇草稿的源码使用“命名空间.类型名.cs:行号”的文字定位，对应本地反编译语料，不提供指向未上传源码的文件链接。文档、图片、SVG 与 DOT 图源均使用相对链接。
